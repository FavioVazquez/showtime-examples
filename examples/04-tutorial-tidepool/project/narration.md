<!-- Tidepool is a fictional demo app. One action per sentence; each action happens as it is said. -->

## hook
Here's how to write a note in Tidepool, tag it, and find it again in seconds.

## create
Click New note, and type a title. Press Enter to move to the body, and start writing. [pause 0.3] Tidepool saves it on this device as you type.

## tag
To tag it, click the tag field under the title. Type a tag, and press Enter. [pause 0.3] The new tag shows up in the sidebar, too.

## search
Later, from any note, press Command K, and type a word from the note. Matches light up as you type. [pause 0.2] Press Enter to jump straight back to it.

## tags
To list every note with a tag, start the search with a hash.

## recap
New note. A tag. Command K. [pause 0.2] That's the whole loop.
